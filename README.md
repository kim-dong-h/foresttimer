# forestTimer

React 기반의 기본 카운트다운 타이머입니다.

UI는 숲속 빈터를 테마로 한 2D 도트 게임 스타일입니다. 배경은 사용자가 선택한 `src/assets/spirit-forest-background.png`이며, 시간을 먹고 성장하는 숲 정령, 퀘스트 대화창, 칸 단위 진행 바를 사용합니다. 한글 픽셀 폰트 Galmuri를 빌드에 포함하므로 외부 폰트 서비스 연결 없이 표시됩니다. 숲 배경 위에 배정된 정령의 투명 PNG를 별도 SVG 이미지로 표시하며, 진화 단계에 맞춰 이미지를 교체합니다.

상단 오른쪽에 **일반 / 집중** 선택 버튼이 있습니다. 두 모드 모두 같은 숲 배경을 사용하고 정령 성장 시간을 누적합니다. 집중 모드에서는 돌아온 기록도 표시합니다.

집중 모드에서 시작한 타이머를 초기화하려고 하면 초기화 버튼 위에 현재 정령과 말풍선이 나타납니다. **계속할게** 또는 Escape로 말풍선을 닫고, **초기화할게**를 누르면 시간을 초기화합니다. 말풍선은 타이머를 멈추지 않으며, 타이머가 완료되면 닫힙니다.

## 실행

```sh
pnpm install
pnpm dev
```

기본 주소: http://127.0.0.1:5173

다국어 주소는 다음과 같습니다. 정적 빌드에도 각각의 `index.html`이 포함되어 서버 라우팅 없이 사용할 수 있습니다.

- `/kr` — 한국어
- `/us` — English

```sh
pnpm build
pnpm test
```

분·초 직접 입력, 저장한 집중 시간 선택, 시작·일시정지·이어서 시작·초기화, 완료 알림음을 지원합니다. 집중 시간은 처음에는 30분 하나이며, **+** 버튼으로 1초~360분까지 분·초 단위로 시간을 추가할 수 있습니다. 기본 30분을 포함해 최대 4개까지 저장되며 중복 시간은 추가되지 않습니다. 기본 30분은 유지되고, 사용자가 추가한 시간은 × 버튼으로 삭제할 수 있습니다. 저장 키는 `onlytimer-presets`이고 새로고침해도 유지됩니다. 이전에 저장한 분 단위 시간도 자동으로 유지됩니다. 타이머 실행 중에는 시간 선택·추가·삭제를 할 수 없습니다. 직접 설정도 최대 360분까지 지원합니다.

타이머는 실제 종료 시각으로 남은 시간을 계산하므로 브라우저의 업데이트 간격이 늦어져도 누적 오차가 생기지 않습니다. 새로고침하면 타이머는 기본 30분으로 돌아옵니다.

제목 오른쪽의 **소리 ON/OFF** 토글로 완료 알림음과 빗소리를 함께 제어합니다. 기본값은 ON이며 설정은 `foresttimer-sound-enabled`에 저장해 새로고침과 언어 경로 이동 후에도 유지합니다. OFF로 전환하면 재생 중인 빗소리와 예약된 완료 알림음도 즉시 음소거됩니다. 빗소리를 선택해 둔 경우 ON으로 되돌리면 다시 들립니다. 브라우저 완료 알림에는 OFF일 때 무음 옵션을 적용합니다.

빗소리는 사용자 제공 `boons_freak-rain-sound-188158.mp3`를 사용합니다. 재생 요청 시 한 번 로딩·디코딩하여 앞뒤의 조용한 구간을 정리하고, 끝과 시작을 3초 동안 크로스페이드한 오디오 버퍼를 반복합니다. 재생 중 반복 경계를 JavaScript 타이머로 예약하지 않으며, 기본 볼륨은 50%입니다. 소리 OFF/ON은 반복 위치를 유지한 채 음소거만 변경합니다.

## 시간을 먹는 숲 정령

첫 방문 시 **새싹 정령 / 버섯 요정 / 이끼 돌 정령** 중 하나를 무작위로 배정합니다. 배정된 종류와 누적 타이머 수행 시간은 로컬스토리지의 `foresttimer-tamagotchi` 키에 저장되어, 새로고침과 재방문 시 같은 정령을 이어서 만납니다. 한국어와 영어 경로는 같은 정령과 기록을 공유합니다.

일반·집중 모드 모두 타이머가 실제로 실행된 시간을 먹고 자랍니다. 누적 **1시간에 1차, 3시간에 2차, 6시간에 3차 진화**하며, 진화 시 캠프의 캐릭터 이미지가 바뀝니다. 캠프 아래에서 누적 시간, 진화 단계와 다음 진화까지 남은 시간을 확인할 수 있습니다. 기존 누적 시간에도 새 진화 기준이 적용됩니다.

일시정지·초기화·시간 변경 전까지 수행한 시간도 유지되고, 멈춘 동안은 누적되지 않습니다. 백그라운드 탭의 늦은 업데이트는 타이머 종료 시각까지만 계산하며, 완료 이후의 시간은 추가하지 않습니다. 1초 간격 및 탭 전환·페이지 종료 시 진행을 저장합니다. 새로고침 후 타이머 자체는 기본 30분으로 돌아오고, 정령의 성장은 유지됩니다. 사이트가 닫혀 있는 동안에는 성장이 진행되지 않습니다. 브라우저 저장이 차단된 경우 현재 페이지에서 성장하며 저장 불가 안내를 표시합니다.

정령 이미지는 `src/assets/tamagotchi/concepts/`와 `src/assets/tamagotchi/evolutions/`에 있습니다. 진화별 이미지와 생성 프롬프트는 `src/assets/tamagotchi/evolutions/README.md`에서 확인할 수 있습니다.

정령 이름 박스 오른쪽 위의 **초기화**를 누르면 확인창이 열립니다. 확인하면 누적 수행 시간·진화 단계·숲 식물을 초기화하고, 현재와 다른 정령을 무작위로 배정해 저장합니다. 취소 또는 Escape는 성장 기록을 변경하지 않습니다. 실행 중인 타이머는 계속 진행하며 확인한 시점 이후의 시간부터 새 정령이 먹습니다. 초기화 세대를 저장하므로 여러 탭이 열려 있어도 이전 성장 기록이 복원되지 않습니다.

## 자라나는 숲

누적 타이머 수행 시간이 **30분** 늘어날 때마다 풀 포기·고사리·덤불·꽃풀·어린 나무 중 하나를 같은 확률로 뽑습니다. 배경의 땅 영역과 군락 밀도에 따라 계산한 800개 자리 중 하나를 선택하며, 이미 자라난 군락 주변에 새 식물이 생길 확률을 높였습니다. 예를 들어 15분씩 두 번 실행해도 식물 하나가 생깁니다. 지연된 업데이트가 여러 구간을 넘으면 해당 개수만큼 추가합니다.

최대는 **누적 400시간 / 식물 800개**입니다. `src/forestLayout.js`에서 고정 시드로 땅의 식재 영역, 나무 뿌리·바위 제외 영역, 23개 군락과 식물 크기에 비례하는 타원형 최소 간격을 계산합니다. 앞쪽 식물은 크고 먼 식물은 작으며 대비가 낮습니다. 중앙 길도 식재 영역에 포함하고 정령 발밑에만 작은 여백을 남깁니다. 화면의 도트 크기는 3 scene pixels를 기준으로 원본 PNG를 투명한 작은 표시 텍스처에 샘플링해 맞춥니다. 풀·고사리·덤불에는 `soft-pixel-v2` 이미지를 사용합니다. 100시간에는 200개, 200시간에는 400개, 300시간에는 600개, 400시간에는 800개가 됩니다. 이후에는 식물 추가만 멈추며 누적 타이머 시간은 계속 기록됩니다. 정령의 진화 시간은 1·3·6시간입니다.

식물 종류와 자리 번호는 `foresttimer-tamagotchi`의 `forestPlants`에 정령 시간과 함께 저장되어 새로고침·초기화 후에도 같은 숲을 유지합니다. 군락 알고리즘 변경 전 기록의 시간·종류·자리 번호는 유지되며, 해당 자리의 화면 위치는 새 배치 규칙으로 재정렬됩니다. 기존 성장 기록에 식물 정보가 없다면 누적 시간에 해당하는 식물을 한 번 생성하여 저장합니다. 화면에서 현재 식물 수와 다음 식물까지 남은 시간을 확인할 수 있습니다. `artifacts/forest-cluster-preview.html`에서 로컬 저장소 변경 없이 실제 렌더러로 0·20·100·200·400시간을 비교할 수 있습니다.

## 집중 모드 기록

집중 모드를 선택하면 정령이 있는 숲 배경 이미지의 밝기·대비·채도를 부드럽게 낮추고, 햇살 위치에 옅은 황금빛을 더합니다. 이 효과는 배경에만 적용되며 타이머·버튼·정령·식물의 조명과 페이지 전체 밝기는 그대로 유지합니다. 일반 모드로 돌아가면 원래 햇살로 복귀하며 전환에는 0.65초 페이드를 사용합니다. 모션 감소 설정에서는 즉시 전환됩니다. 조명 레이어는 클릭과 키보드 조작을 가로채지 않습니다.

**집중** 모드에서만 타이머 실행 중 다른 탭·창 또는 모바일 앱으로 전환했다가 사이트로 돌아오면 **돌아온 기록**에 시각과 시작 후 경과 시간이 표시됩니다. 모바일의 앱 전환·복귀 이벤트와 브라우저 탭 전환을 함께 감지하며, 같은 복귀에 발생하는 여러 이벤트는 한 번만 기록합니다. 일시정지·초기화·완료 이후에는 기록하지 않습니다. 일반 모드에서는 기록을 표시하거나 새 기록을 만들지 않으며, 초기화 버튼을 누르면 바로 초기화합니다.

최근 한 번의 타이머 기록은 이 브라우저의 로컬 저장소에 저장되어 새로고침 후에도 확인할 수 있습니다. 초기화와 시간 설정은 기록을 유지하고, 새 타이머를 시작하면 새 기록으로 바뀝니다. 타이머 자체는 새로고침 시 기본 30분으로 돌아옵니다. 기록은 다른 화면에서 무엇을 했는지 또는 실제 집중 여부를 판단하지 않습니다.

집중 모드의 타이머가 종료되면 기록의 시작 시각, 각 돌아온 시각, 종료 시각 사이를 비교해 **최장 집중 구간**을 표시합니다. 이는 타이머를 다시 확인하기까지 가장 길게 이어진 구간이며, 실제 집중 여부를 단정하는 값은 아닙니다. 집중 모드에서 실행 중 또는 일시정지 중 초기화를 누르면 정령이 제지하는 말풍선을 표시합니다.

## 브라우저 완료 알림

타이머 아래의 **완료 알림 → 켜기**를 누르고 브라우저에서 알림 권한을 허용하세요. **테스트**로 기기에 알림이 표시되는지 확인할 수 있습니다. 알림 설정은 이 브라우저에 저장되며, 알림을 누르면 타이머 탭으로 돌아옵니다. 일시정지·초기화 시에는 완료 알림이 발송되지 않습니다.

서버 없이 Notifications API와 정적 서비스 워커를 사용합니다. 탭을 열어 둔 상태에서 다른 탭을 보는 동안에도 완료 알림을 표시할 수 있습니다. **탭을 닫거나 브라우저가 탭 실행을 중단하면 알림을 예약·발송할 수 없습니다.** 기기 절전이나 백그라운드 제한으로 알림이 늦어질 수 있습니다. 이것은 서버에서 전달하는 Push API 방식이 아닙니다.

알림에는 HTTPS 배포(로컬 개발은 localhost 또는 127.0.0.1 허용), 지원 브라우저, 브라우저·운영체제의 알림 허용이 필요합니다. 지원하지 않거나 차단된 환경에서는 안내를 표시하며 기본 타이머는 그대로 사용할 수 있습니다.

## 정적 배포

`pnpm build`로 생성된 `dist/` 전체를 HTTPS 정적 호스팅에 업로드하면 됩니다. Node 서버나 백엔드는 필요 없습니다. `sw.js`와 `notification-icon.svg`도 함께 업로드하세요. 상대 경로를 사용하므로 하위 폴더 배포도 지원합니다.

## 앱으로 설치

`manifest.webmanifest`와 192·512px PNG 앱 아이콘을 포함합니다. Chrome 또는 Edge에서 설치하면 forestTimer 아이콘으로 실행할 수 있으며, 브라우저 탭 대신 별도 앱 창으로 열립니다. `dist/`의 매니페스트와 `icons/` 폴더도 함께 배포하세요.

로컬에서는 `http://127.0.0.1:5173/` 또는 `http://localhost:5173/`, 배포 시에는 HTTPS 주소에서 확인하세요. `http://192.168.45.108:5173/` 같은 일반 HTTP 사설 IP 주소는 설치 기능을 확인하는 데 적합하지 않습니다. Chrome 주소창의 설치 아이콘 또는 메뉴의 **전송, 저장, 공유 → 페이지를 앱으로 설치**를 사용하세요. 메뉴 이름과 설치 아이콘 표시 시점은 브라우저 버전·사용 기록에 따라 달라질 수 있습니다.

설치해도 실행에 서버 연결이 필요합니다. 오프라인 캐시는 제공하지 않으며, 로컬 설치의 경우 개발 서버를 켜 두어야 합니다. 앱 창을 닫으면 타이머와 완료 알림도 계속 실행되지 않습니다.
